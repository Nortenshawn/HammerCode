# HammerCode

> **Forge ideas into working software.**

HammerCode 是南京大学软件学院预推免“构建编程智能体”项目考核作品，目前处于开发阶段。

## 理念

HammerCode 希望成为开发者手中直接、可靠的工具：理解自然语言描述的目标，并将想法一步步锻造成可以运行的软件。

项目不只关注代码生成，也重视本地执行、过程透明与行为可控。我们计划自主实现对话循环、上下文管理、工具调用、文件操作、命令执行和错误处理等核心机制，让每一步行动都清晰、可追踪、可解释。

## 当前状态

项目正在进行产品设计与基础架构搭建。功能说明、运行方式和演示将在实现后陆续补充。
